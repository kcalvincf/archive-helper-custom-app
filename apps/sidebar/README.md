# Archive Helper — Sidebar

React entry sidebar (Vite + Contentful App SDK + Forma 36).

**Full how-to:** [docs/guides/sidebar.md](../../docs/guides/sidebar.md)

Quick start:

```bash
# from repo root
npm run build -w @archive-helper/shared-types
cp apps/sidebar/.env.example apps/sidebar/.env
# optional: VITE_CONTENTFUL_APP_DEFINITION_ID, VITE_CONTENTFUL_APP_ACTION_REMOVE_LINKS_ID
npm run dev -w @archive-helper/sidebar
```
